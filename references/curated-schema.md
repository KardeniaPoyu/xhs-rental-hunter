# curated.json 格式

复核完成后写入 `<work-dir>/curated.json`，`render-poster` 会优先使用它。
每个条目只需写 `id` 和你想覆盖的字段；没写的字段（图片、作者、规则分、价格等）会自动从
`analyzed_results.json` 中按 `id` 补全。卡片按数组顺序排列。

```json
{
  "title": "北京朝阳 · 东坝个人整租精选",
  "subtitle": "预算 3500-5000 · 一居/两居 · 近 30 天",
  "entries": [
    {
      "id": "6650a1b2c3d4e5f6a7b8c9d0",
      "headline": "东坝华瀚福园C区 · 两居室整租 62㎡",
      "price_text": "4500元/月（押一付三）",
      "meta": "两室一厅 · 5层无电梯 · 褡裢坡站步行10分钟",
      "rows": [
        ["房源配置", "两卧均配 1.5m 床和衣柜，送沙发、书柜、洗衣机；民水民电"],
        ["转租原因", "工作调动离京，已住两年"],
        ["签约方式", "可与房东重签，合同可续到 27 年 3 月"]
      ],
      "diagnosis": "转租原因、合同期限、家具交接与缺点说明都很具体；主页 9 篇均为生活内容。",
      "tier": "trusted"
    },
    {
      "id": "6650ffffeeee000011112222",
      "headline": "“化妆师”人设 · 朝阳精装一居",
      "is_warning": true,
      "diagnosis": "主页另有 7 篇不同小区房源；标签堆叠、引导加微信；全新装修首次出租。"
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `id` | 必填，帖子 id（见 review.md） |
| `headline` | 卡片标题，建议“小区/商圈 · 户型 面积” |
| `price_text` | 价格文本；不写则用抽取结果，抽不到显示“价格私询” |
| `meta` | 标题下的灰色信息行 |
| `rows` | 右侧信息行 `[标签, 内容]`，建议 2~4 行、标签 2~4 个字；每行最多显示 2 行文字 |
| `diagnosis` | 鉴别诊断（最多 3 行），写证据而不是形容词 |
| `tier` | `trusted`（绿）/ `verify`（橙）/ `suspect`（红） |
| `is_warning` | `true` 时作为避坑案例（红框） |
| `tag` | 可选，自定义左上角标签文字 |

也可以直接写一个数组（等同于只有 `entries`）。
