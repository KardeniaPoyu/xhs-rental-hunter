# SkillPay 商品材料

## 商品名称

Rental Hunter｜租房候选对比与询问准备

## 商品描述（500 字内）

把用户提供或经授权采集的租房帖子按预算与整租/合租偏好整理成 HTML 对比报告，每个判断附原文依据，列出条件冲突、缺失信息和询问草稿。核心流程本地离线运行，不需模型或 API 账号。可选 Chrome 采集为实验适配器，需自行登录与配对；不保证网页采集持续可用。不核实房东身份或房屋质量，不支付押金，不自动联系发布者。

## 演示

三条原创合成候选：展示预算内整租、与偏好冲突的合租、月租未知；打开对应依据和询问草稿，明确没有发送评论。

## 支付与上架边界

本项目通过 SkillPay 销售技能文件，不另写一个未经文档支持的收费接口，
不接管用户付款授权。推荐先验证一次性购买、本地执行的交付方式。
周期付费依赖平台云端执行，Python、FFmpeg、模型或浏览器能力是否可用尚待核实。
