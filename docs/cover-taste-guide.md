# 小红书高审美原生封面设计与规范指南 (Cover Taste Guide)

## 1. 核心审美哲学 (Taste Philosophy)

> **真实 > 炫技，原生 > 浮夸，可读性 > 复杂背景。**

在小红书双列瀑布流推荐页中，用户单手握持手机，每个卡片在视网膜屏幕上只有约 4~5cm 宽。用户在浏览时停留在单张封面上的时间通常**不足 0.5 秒**。

- **高点击率（CTR）封面的本质**：在 0.5 秒内，用**大字**将最核心的情绪共鸣（如“被拷打麻了”）、最高价值的信息点（如“14道Unity核心八股”）准确传递给目标受众。
- **低点击率封面的通病**：满屏花哨背景、赛博朋克炫光、复杂 3D 立方体，字又小又扁，读者一眼看出是“批量 AI 营销号”，本能地快速滑过。

---

## 2. 严禁清单：彻底去除“AI 味” (Anti-AI Taste)

发布内容时，封面**严禁**出现以下元素：

1. ❌ **严禁赛博朋克霓虹光晕**：深蓝紫渐变、发光网格、电路板纹理、科幻线条。
2. ❌ **严禁浮夸 3D 悬浮物**：漂浮的发光水晶立方体、金属机械手、透明玻璃球体、虚拟粒子特效。
3. ❌ **严禁彩虹渐变与金属塑料感艺术字**：文字带厚重 3D 倒角或彩虹流动高光。
4. ❌ **严禁低对比度复杂背景**：背景色与文字颜色接近，或者背景元素杂乱导致文字识别困难。
5. ❌ **严禁画面无核心重点**：一堆无意义的 AI 生成插图，缺乏真实人感。

## 3. 四大小红书原生爆款文字封面流派

### 风格 A：极简白底荧光笔大字报 (`minimal_light`)
- **适用场景**：面经复盘、学习干货、避坑指南、方法论总结。
- **视觉特征**：
  - 底色：冷淡素雅的浅灰白（`#F4F4F3`）搭配微投影白卡片（`#FFFFFF`）。
  - 大标题：超大黑体（88px~96px），核心痛点关键词下方叠加**荧光黄标记笔涂抹效果**（`#FFE14D`）。
  - 亮点盒：浅灰底色块，3~4 条带点缀符（`✦`）的核心要点。
  - 顶部与底部：胶囊标签（Pill Badge）与极简作者署名。

### 风格 B：真实 iOS 备忘录手感 (`memo`)
- **适用场景**：学生党/求职者真实手稿、真题整理、私人复习计划。
- **视觉特征**：
  - 质感：模拟 iOS 备忘录经典的微黄纸质感（`#F7F6F2`），保留黄色返回箭头与文件夹分类。
  - 勾选清单：圆形对勾（`✓`）与浅色便签条，给读者“这是博主私人整理的真题原件”的强烈真实信任感。

### 风格 C：程序员 IDE / 终端极客风 (`dark_terminal`)
- **适用场景**：游戏客户端/后端/算法岗面经、代码解析、开源项目拆解。
- **视觉特征**：
  - 质感：深色终端窗口（macOS 经典红黄绿三色圆点 🔴🟡🟢，`#0D1117` 底色）。
  - 代码化排版：等宽字体（Consolas / JetBrains Mono），行号配合语法高亮（如 `yield "14道Unity核心八股";`）。
  - 纯粹技术人质感，彻底告别假科幻，展现扎实工程功底。

### 风格 D：醒目高反差大字报 (`bold_contrast`)
- **适用场景**：重大热点、高能警示、高密度干货合集。
- **视觉特征**：
  - 配色：明亮黄黑（`#F6D84C` + `#111111`）强反差。
  - 超大粗黑字体，自带爆款视觉抓取力，穿透力极强。

## 4. 自动化生成命令 (CLI 命令参考)

所有封面均由 `scripts/cover_generator.py`（基于 Chrome Headless）本地无损渲染为 3:4 比例（1080×1440）PNG：

```bash
# 生成极简白底荧光笔封面
python scripts/cli.py generate-cover \
  --style minimal_light \
  --tag "2026秋招 · 客户端一面" \
  --title "途游客户端一面\n被拷打麻了" \
  --highlight "被拷打麻了" \
  --points "14道 C#/Unity 核心硬核八股" "协程底层、AB包与性能优化深挖" "8道游戏项目架构与防守细节" \
  --footer "真题硬核复盘 · 攒人品求Offer" \
  --author "小菲在coding" \
  --output "/path/to/cover.png"

# 生成真实 iOS 备忘录封面
python scripts/cli.py generate-cover \
  --style memo \
  --tag "途游客户端一面" \
  --title "秋招一面被拷打麻了[哭惹R]" \
  --points "14道 C#/Unity 核心八股真题" "协程底层、AB包加载与性能优化" "8道游戏项目架构深挖与细节" \
  --footer "攒人品求Offer！有疑问欢迎交流" \
  --output "/path/to/cover.png"

# 生成程序员终端代码风封面
python scripts/cli.py generate-cover \
  --style dark_terminal \
  --tag "2026秋招 · 客户端一面" \
  --title "途游客户端一面\n真题八股+项目复盘" \
  --points "14道C#/Unity高频核心八股" "协程底层原理与AB包优化" "8道项目架构深挖与反问" \
  --footer "运行通过 · 积攒人品求Offer" \
  --output "/path/to/cover.png"
```
